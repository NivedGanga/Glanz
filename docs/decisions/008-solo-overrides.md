# 008: Solo-owner boundaries

Use a single deployable app rather than microservices, one relational store for jobs/flags/events, email digests instead of per-request push, manual moderation rather than stock-image detection, manual rental blocks instead of booking/payment infrastructure, and entitlement defaults rather than billing. The public profile always shows the shop phone. Never rank by plan. No payments, auto-match, or later-run tables/routes/UI/flags ship in Run 1.
